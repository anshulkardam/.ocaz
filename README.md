
# Ocaz - A Movie Ticket Booking App

Ocaz is a modern movie ticket booking platform where users can discover movies, view show timings, pick seats, and book instantly, while admins manage listings, screens, and bookings from a single dashboard.


## Run Locally

Clone the project

```bash
  git clone https://github.com/anshulkardam/ocaz.git
```

Go to the project directory

```bash
  cd ocaz
```

Install dependencies

```bash
  bun install
```

Start the server

```bash
  bun dev
```


## Environment Variables

To run this project, you will need to add the following environment variables to your .env file

`NEXT_PUBLIC_API_URL`

`ANOTHER_API_KEY`


## Tech Stack

Next.js 16, tRPC, Prisma, PostGreSQL, MapGL, TailwindCSS, Tanstack Query, Zod, ShadCN
